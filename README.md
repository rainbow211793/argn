# argn


## What is argn?

**Argn** is a project intended on supporting archiving efforts of the entity **Gifstad** via a system that allows users to submit media to be added to the website that will then be accepted or denied [via email] and add the media [aslong as it is not a massively unreasonable file] in it's original form and use it to distribute [downloads of the media for public usage], create [media can be used to make new content] and save [content can be safely kept in a tagged search database in github instead of someone's crusty hard drive or worse their phone's camera reel]. All of these use cases are especially demanding because Gifstad was made Nov 28th 2024 what is quite a long time ago from now.
